# 2026-06-05 작업 로그

## Today
- Backend: 댓글 엔티티와 댓글 작성/조회 API를 추가하고, 댓글 조회 응답을 엔티티 직접 반환이 아닌 `ReadComment` DTO로 분리했다.
- Frontend: 게시글 상세 화면에 댓글 작성과 댓글 목록 조회를 연결하고, 백엔드의 필드별 에러 메시지를 공통 HTTP 처리에서 읽을 수 있도록 수정했다.

## Learned
- 엔티티를 그대로 응답으로 내리기보다 조회용 DTO를 만들어 필요한 필드만 내려주는 방식이 더 안전하고 유지보수하기 좋다.
- `stream().map(ReadComment::from).toList()`는 서비스에서 직접 `new`로 DTO를 만드는 대신, DTO 변환 책임을 DTO 내부로 옮기는 방식이다.

## Troubleshooting
- 댓글 조회 응답을 엔티티 그대로 반환하면 내부 필드가 과하게 노출될 수 있어, 화면에 필요한 값만 담는 `ReadComment` DTO로 응답 구조를 정리하고 `ReadComment.from()`으로 변환 책임을 분리했다.
- 백엔드가 `{post: "..."}`, `{content: "..."}`처럼 필드별 에러를 내려줄 때 프론트가 `auth`, `message`만 읽고 있어 기본 메시지가 표시되던 문제를 공통 에러 파싱 로직으로 보완했다.
    - https://min-soon.tistory.com/76

## Blocker
- 댓글 조회 기능은 동작하지만 아직 작성자 닉네임, 내 댓글 여부, 대댓글 구조는 응답에 포함되어 있지 않다.
