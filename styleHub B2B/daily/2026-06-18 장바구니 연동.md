# 2026-06-18 작업 로그

> 관련 글: [Spring Boot와 React의 장바구니 데이터 연동 기록](https://min-soon.tistory.com/87)

## Today

- 요청 DTO에서 `userId`를 제거하고 `@LoginUser`의 인증 사용자로 장바구니 API를 처리하도록 변경했다.
- 상품 상세의 장바구니 추가와 장바구니 조회 화면을 실제 API에 연결했다.
- 하드코딩 데이터를 제거하고 `cartType`으로 일반 주문과 샘플 주문을 구분했다.
- 실제 Response DTO에 존재하는 데이터 기준으로 화면을 정리했다.

## Learned

- 요청에는 사용자가 선택한 값만 담고 사용자와 가격 정보는 서버에서 확인해야 한다.
- Response DTO는 백엔드 응답과 React 화면 사이의 데이터 계약이다.
- Axios의 `withCredentials`를 설정하면 HttpOnly 인증 쿠키가 요청에 함께 전달된다.

## Troubleshooting

- 로컬 의존성이 설치되지 않아 Axios와 Zustand의 Vite import 오류가 발생했다.
- `npm install`로 `package.json`과 로컬 모듈을 동기화해 해결했다.
