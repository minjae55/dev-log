## Learned

- 요청 DTO에는 사용자가 직접 선택한 `productOptionId`, 수량, 장바구니 유형만 전달하는 것이 적절하다.
- 사용자 ID는 클라이언트 요청을 신뢰하지 않고 인증 정보에서 가져와야 한다.
- 상품명과 가격은 서버가 DB에서 조회해 데이터의 신뢰성을 보장해야 한다.
- React는 API 응답을 state에 저장하고, 변경된 state를 기준으로 화면을 다시 렌더링한다.
- Response DTO는 백엔드 데이터와 프론트 화면을 연결하는 데이터 계약 역할을 한다.
- Axios의 `withCredentials`를 설정하면 HttpOnly 인증 쿠키가 API 요청에 자동으로 포함된다.

## Issue

- `npm install`을 실행해 로컬 의존성을 최신 상태로 맞춰 해결했다.
