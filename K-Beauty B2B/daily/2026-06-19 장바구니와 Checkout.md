# 2026-06-19 작업 로그

> 관련 글: [장바구니 회사별 배송비 그룹화와 JPA N+1 문제, @EntityGraph로 개선](https://min-soon.tistory.com/88)

## Today

- 회사별 배송 정책과 옵션별 샘플 가격·최대 수량을 데이터 구조에 추가했다.
- 장바구니 조회, 수량 변경, 삭제 API를 React 화면과 연결했다.
- 같은 사용자·상품 옵션·장바구니 유형은 새 행 대신 기존 수량을 증가하도록 처리했다.
- 일반·샘플 주문 정책을 구분하고 회사별 배송비를 계산하는 Checkout 미리보기를 구현했다.

## Learned

- 장바구니 변경 시 항목 ID와 인증 사용자 ID를 함께 조회해 소유권을 검증해야 한다.
- 배송비는 회사별 상품 금액을 합산한 뒤 각 회사의 무료 배송 기준을 적용해야 한다.
- Checkout에서는 클라이언트 금액을 신뢰하지 않고 서버가 상품과 주문 정책을 다시 검증해야 한다.

## Troubleshooting

- 배송비 계산 중 상품 옵션, 상품, 회사 연관관계를 항목마다 조회하면 N+1 문제가 발생할 수 있었다.
- 조회 메서드에 `@EntityGraph`를 적용해 필요한 연관 데이터를 함께 가져오고 기본 연관관계는 `LAZY`로 유지했다.
