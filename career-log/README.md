# Career Log

취업과 커리어 활동을 기록하는 공간입니다.

회사명처럼 외부에 공개하기 조심스러운 정보는 남기지 않고, 면접에서 받은 질문과 내가 한 답변, 부족했던 부분, 다음 지원 전에 보완할 내용을 중심으로 정리합니다.

## 기록 범위

- `interviews`: 면접 질문, 답변, 분위기, 회고
- `resume`: 이력서와 포트폴리오 수정 방향
- `job-postings`: 채용공고를 보고 파악한 요구사항
- `applications`: 지원 내역과 전형 진행 상황

## 면접 기록 원칙

- 회사명은 비공개로 두고 회사 성격, 위치, 포지션 정도만 남긴다.
- 질문은 가능한 한 실제 표현에 가깝게 기록한다.
- 답변은 잘 말한 내용과 보완할 내용을 분리해서 적는다.
- 떨어졌는지 붙었는지보다, 다음 면접에서 무엇을 더 잘 말할 수 있는지를 남긴다.
- 이력서나 포트폴리오에 반영할 부분이 보이면 따로 표시한다.
